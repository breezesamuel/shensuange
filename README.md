# 神算阁 · 长辈放心用

> 为父母做的"大按钮"网页应用：大按钮计算器、到点大声提醒吃药（语音播报）、一键呼叫家人。
> **零广告、零弹窗、零诱导** —— 符合工信部《移动互联网应用（APP）适老化通用设计规范》。

## 在线版（免费可用）
- 长辈端：https://tools.highkingflower.com/elder/
- 家人端（孝心卡）：https://tools.highkingflower.com/elder/family.html

## 特性
- 26px 正文 + 76px 触控目标 + 高对比配色，专门为老花眼与颤抖的手指设计
- 吃药提醒：本地存储（数据不出手机），到点高亮 + 语音朗读药名（SpeechSynthesis）
- 大按钮计算器：四则运算，防误触布局
- 一键呼叫：tel: 直拨家人号码
- 家人订阅（¥9.9/月）：解锁无限提醒组 + 语音播报 —— 订阅不是向长辈收费，是子女的孝心卡

## 自部署
两个静态 HTML 文件，任何静态托管都能跑（Vercel / GitHub Pages / nginx）。
复制 elder/ 目录即可；订阅后端需要自己的 KV（结构见 family.html 内注释）。
